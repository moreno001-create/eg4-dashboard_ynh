Dashboard for EG4 solar inverters (built for the 6000XP), read from the EG4 Monitor cloud.

- Live power flow: solar, battery, grid and home
- Today's and lifetime energy, 24-hour charts, 30-day and 12-month history
- Battery bank and per-module details (health, cycles, cell voltages, temperatures)
- Faults and warnings from the inverter's event log, offline detection
- Start/stop charging the battery from the grid (EG4 Quick Charge), with an optional automatic stop level

Not affiliated with EG4. The unofficial API may change without notice.
